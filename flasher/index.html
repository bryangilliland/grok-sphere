Grok Sphere — Thad + Claude Edition

Browser installer for Windows (use Google Chrome or Microsoft Edge).

  1. Plug the sphere into your Windows PC using a USB-C data cable (plug directly into the PC, not a hub).
  2. Click Install below, pick the port named USB JTAG/serial debug unit (or USB Serial Device) under COM ports, and click Connect.
  3. If asked about Erase device: leave it unchecked to keep your saved Wi-Fi settings, or check it for a clean wipe.
  4. When finished, unplug and replug (or press RESET). The original two white eyes appear!
This browser cannot flash boards over USB. Open this page in Google Chrome or Microsoft Edge on Windows. Open this page via serve_web_flasher.bat (http://localhost:8000) or https://.
No COM port shows up in Windows?
  1. Hold the sphere's BOOT button while plugging in the USB cable, keep holding for 2 seconds, then release. (Or hold BOOT and tap RESET.)
  2. Try a known data USB-A-to-USB-C cable in a rear/direct PC USB port — many USB-C cables are power-only.
  3. Check Windows Device Manager → Ports (COM & LPT). See the README for the 1-minute Windows driver fix if it appears under Universal Serial Bus devices with a warning icon.
